# Checklist: Text

This is the "Text" section of `references/checklist.md`, for one section critic of the deep mode.

Generated by `scripts/build.rb` from `checklist.yaml` and crit's GUIDELINES.md. Do not edit by hand.

Each line is a question. Yes means the design is fine there; no means a defect. Each kind of defect has exactly one question, so file a defect under one line only. Sections run from the whole piece to the detail. When a question in "Charts and data", "Interface", or "Template tells" names a defect, file it there and not under a general question; text inside a chart or a control is still asked under "Text". Skip a section that does not apply (no chart, no controls). Each line names the reference files and entry titles it stands for. To open the entries of a line, run `node scripts/entries.mjs "<title>" "<title>"` with the script's full path in the skill folder and each title as the line quotes it; it prints each entry in full, with the Rule, Look for, How bad it gets, Fix, and Caveat. One call can open the entries of several lines. For one entry, the Read tool on the file the line names works too: find the `###` heading with the entry's title. Open the entries when the answer is no or unsure. A line that names no entry is a defect the catalog does not cover: judge it as taste or common sense, and say so.

Setting and reading text, outside charts and controls.

- [ ] **Are captions, labels, and legal text large enough to read (11 pt or more on iOS)?** → `references/basics.md` "Captions and labels are not too small to read"

- [ ] **Do the typefaces follow one plan, one family or a few plainly different faces, with no face that nearly matches another and no extra unrelated face?** → `references/typography.md` "Typefaces in concord or in clear contrast, never in conflict"
- [ ] **Is small text set in a weight heavy enough to hold up, with hairline weights kept to large sizes?** → `references/typography.md` "Weight and stroke thickness at small sizes"
- [ ] **Does text on a plain background reach 4.5:1 contrast (3:1 for large text), placeholder and helper text included?** → `references/basics.md` "Text does not read as faint"; `references/color.md` "Body text contrast (WCAG AA)"; `references/accessibility.md` "Text contrast (minimum)"; `references/color.md` "Placeholder, disabled and decorative text exemptions"
- [ ] **Does text over a photo, gradient, or texture stay readable at the worst point behind it?** → `references/layout.md` "Figure and ground are unambiguous"; `references/color.md` "Text over images and gradients"

- [ ] **Do paragraphs and columns break cleanly, with no lone short word on a last line and no heading at the foot of a column?** → `references/typography.md` "Widows, orphans, and runts"
