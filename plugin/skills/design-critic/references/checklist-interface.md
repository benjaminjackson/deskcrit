# Checklist: Interface

This is the "Interface" section of `references/checklist.md`, for one section critic of the deep mode.

Generated by `scripts/build.rb` from `checklist.yaml` and crit's GUIDELINES.md. Do not edit by hand.

Each line is a question. Yes means the design is fine there; no means a defect. Each kind of defect has exactly one question, so file a defect under one line only. Sections run from the whole piece to the detail. When a question in "Charts and data", "Interface", or "Template tells" names a defect, file it there and not under a general question; text inside a chart or a control is still asked under "Text". Skip a section that does not apply (no chart, no controls). Each line names the reference files and entry titles it stands for. To open the entries of a line, run `node scripts/entries.mjs "<title>" "<title>"` with the script's full path in the skill folder and each title as the line quotes it; it prints each entry in full: the Rule and Source, and the Look for, How bad it gets, Fix, and Caveat lines when the entry has them. One call can open the entries of several lines. For one entry, the Read tool on the file the line names works too: find the `###` heading with the entry's title. Open the entries when the answer is no or unsure. A line that names no entry is a defect the catalog does not cover: judge it as taste or common sense, and say so.

## Interface

Buttons, links, fields, menus, navigation, and the messages about them. Text inside a control is still asked under Text. Skip it when the piece has no controls.

- [ ] **Do input borders, control edges, and meaningful icons reach 3:1 contrast against what is next to them?** → `references/color.md` "Non-text contrast"; `references/accessibility.md` "Non-text contrast"
- [ ] **Do the hover, pressed, and disabled states shown each look distinct from the default?** → `references/ux.md` "Norman: Feedback"; `references/color.md` "Color for state: hover, focus, disabled"
- [ ] **Does a focused control show an indicator at least 2 px thick with 3:1 contrast?** → `references/accessibility.md` "Focus visible"; `references/accessibility.md` "Focus appearance"
- [ ] **Is a focused control left uncovered by sticky headers, banners, or chat widgets?** → `references/accessibility.md` "Focus not obscured (minimum)"
