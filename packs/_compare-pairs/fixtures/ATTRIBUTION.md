# Fixture attribution: _compare-pairs

Pack license: MIT

This folder holds the EV-9 before-and-after pairs, not a pack. Each template draws one design twice: with the defect switch on it shows one criterion's defect, or for a `same-` template one detail that no criterion covers, and with it off it does not. `evals/compare-pairs/labels.json` says which image of each pair is the before and which is the after. packs/README.md defines the entry format.
