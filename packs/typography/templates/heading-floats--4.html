Release notes

Version 4.2 · 18 October

Shared folders now show who changed each file and when. Hover over a file name to see the last five changes.

Search results load about twice as fast on large workspaces.

Version 4.1 · 2 October

You can now pin up to ten folders to the sidebar. Pinned folders stay in the same order on every device you sign in on.

Version 4.0 · 11 September

A new editor replaces the old one. Tables, checklists, and code blocks can be added from the slash menu, and every document keeps a full history.

The desktop app no longer supports systems older than five years.
