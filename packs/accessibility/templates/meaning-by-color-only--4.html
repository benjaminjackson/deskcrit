Pagination

Every list endpoint returns at most 100 items per page. Each response includes a next_cursor field; pass it back as the cursor parameter to read the next page. Cursors expire after one hour, as described in cursor lifetime.

GET /v2/shipments?limit=50&cursor=c_8f2a1e

When next_cursor is empty, you have reached the last page. Items created while you page through a list may appear on a later page or not at all; if you need a stable view, filter by creation time as shown in filtering by date.

Rate limits

Paging through a large list counts as one request per page. If you read lists often, consider subscribing to webhooks instead, so that your service learns about new shipments without polling.
