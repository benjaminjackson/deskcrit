Exporting your invoices as a CSV file

You can export every invoice from the last twelve months as one CSV file, which opens in any spreadsheet program.

What the file contains

Each line of the file is one invoice. The columns are, in this order:

  • the invoice number and the date it was issued;
  • the customer name and their tax number, if they gave one;
  • the amount before tax, the tax, and the total.

Drafts and invoices that were voided are left out, so the totals may differ from the figures on your dashboard.

How long it takes

Exports run in the background, so you can keep working while the file is prepared. Large accounts with several thousand invoices can take a few minutes.

We send a link to the address on the account when the file is ready. The link stays valid for seven days, and after that you can start a new export from the Invoices page.
