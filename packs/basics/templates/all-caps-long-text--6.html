Exporting your invoices as a CSV file

You can export every invoice from the last twelve months as one CSV file, which opens in any spreadsheet program. The file lists the invoice number, the date it was issued, the customer name, the amount before tax, the tax, and the total.

Exports run in the background, so you can keep working while the file is prepared. We send a link to the address on the account when the file is ready to download.

Exports include only invoices that have been sent. Drafts and invoices that were voided do not appear in the file, so the totals may differ from the figures on your dashboard.
