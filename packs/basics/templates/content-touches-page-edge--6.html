Importing GPX files

Trailmap can read routes and waypoints from any GPX file, such as one exported from a running watch or a bike computer. Each track in the file becomes one layer on the map.

Tip: name each layer when you import it, so you can tell the tracks apart later.

Waypoints keep their names and are drawn as small markers. If the file has no track, only the waypoints are imported.
