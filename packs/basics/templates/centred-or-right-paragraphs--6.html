Exporting your invoices as a CSV file

You can export every invoice from the last twelve months as one CSV file, which opens in any spreadsheet program. The file lists the invoice number, the date it was issued, the customer name, the amount before tax, the tax, and the total, with one invoice on each line.

Exports run in the background, so you can keep working while the file is prepared. Large accounts with several thousand invoices can take a few minutes, and we send a link to the address on the account when the file is ready to download.

The download link stays valid for seven days. After that, start a new export from the Invoices page to get a fresh copy of the file with every invoice that was added since your last export.
