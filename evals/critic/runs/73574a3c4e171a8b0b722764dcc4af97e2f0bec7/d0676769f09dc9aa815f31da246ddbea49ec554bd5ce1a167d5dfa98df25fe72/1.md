**First read.** The five screens read as one product. They share the same sidebar, the same 264 px content edge, the same title and subtitle pair, the same white cards on a pale gray background, and the same cobalt accent. The set stops feeling like one product when you read what is on the screens. From Carriers onward, the page title says one thing and the content below it belongs to a different section.

**Verdict.** The visual system holds together, but the content does not stay matched to the sidebar labels. Carriers, Rates and Documents each reuse another section's parts. That's the biggest break: someone moving through the sidebar can't trust that a label leads to what it names.

**Breaks**
1. **Each section's content matches its name: tiles 1 and 5 keep this; tiles 2, 3 and 4 break it.**
   - **Tile 2, "Carriers / Who hauls for you":** shows the same Shipments table as tile 1, with the same four rows (CF-88102 to CF-88115), under a "Shipments" subheading, plus "Book shipment" and "Get quote" buttons. No carrier appears anywhere.
   - **Tile 3, "Rate quotes / Compare prices for a lane":** repeats tile 1's three stat cards (In transit 48, Awaiting pickup 11, Delivered 212) and then shows carrier cards. These are the carrier list that tile 2 should hold. There are no prices or lanes to compare.
   - **Tile 4, "Documents / Bills of lading and customs forms":** shows a booking form (Origin, Destination, Weight, Pickup date) with a "Book shipment" button. No document appears.

   What this does to the user: a user who clicks Carriers sees their shipments again and assumes the click didn't register. A user who opens Documents to find a bill of lading lands in a booking flow. "Book shipment" now sits on two screens, Carriers and Documents, and neither is Shipments, so the user can't learn where booking lives. This is the consistency-and-standards problem in Nielsen's heuristics: the same thing should have one name and one place. **Defect.** The fix: give each screen the content its title promises. Carriers should hold the carrier list, which tile 3 already has. Rates should hold rates for a lane. Documents should hold the documents. Booking should live in one home, most likely Shipments, and be reached from there.

2. **Each icon has one meaning: the sidebar sets it on every tile; tile 3 breaks it.** The carrier cards on tile 3 use the sidebar's own icons: house (Shipments) for Northline Haulage, three lines (Carriers) for Vela Transport, bar chart (Rates) for Iberia Cargo. They're drawn in the active blue, the same as the selected nav item. The icons therefore point the user to sections the cards have nothing to do with, and the three carriers look like they differ by type when they don't. **Defect, minor in impact but on a shared element.** The fix: either drop icons from the carrier cards or use one neutral carrier icon. Keep the nav icons for navigation only.

**Smaller things.**
- **Tile 5:** the settings list ends at about 824 px, while every other screen runs content to 1240 px. A narrower column keeps each toggle near its label, so this is defensible. Still, the right edge is the only one in the set that moves. Either keep the narrow width as the deliberate rule for forms and settings, and apply the same width to tile 4's form, or extend the rows. **Taste.**
- **Tiles 2 and 4:** on Carriers the button pair is filled plus outlined ("Book shipment" / "Get quote"), and on Documents the same pair is "Book shipment" / "Cancel". The outlined button means "secondary action" on one screen and "abandon" on the other. Settle what the outlined style stands for once the booking flow has a single home.

**What's working.**
- **Grid:** the content edge (264 px), the right edge (1240 px, except tile 5), the title baseline and the 128 px start of the first content block are identical on every screen. The page never jumps when you switch sections.
- **Components:** the white cards with light borders, the stat cards, the table and the status pills look the same wherever they appear. When the content is fixed, the pieces already match each other.
- **Active nav state:** the tinted background, blue label and blue icon are the same on all five screens. It's clear which section you're in, which also makes the mismatched content stand out.
