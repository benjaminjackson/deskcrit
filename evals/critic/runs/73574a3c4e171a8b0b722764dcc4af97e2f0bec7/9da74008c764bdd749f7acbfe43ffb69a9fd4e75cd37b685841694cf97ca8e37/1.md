**First read.** All six screens read as one product, Tidewise. The sidebar is the same on every screen. The page title, subtitle and section heading sit in the same places, the content starts and ends at the same edges, and every screen uses the same teal color for actions. The only place the set stops feeling like one product is the pair of buttons on Crew: they are noticeably rounder than the buttons on Boats.

**Verdict.** The set holds together well. The one real break is the button shape on tile 4 (Crew).

**Breaks**
1. **Button corner radius**: tile 2 (Boats) sets the button style; tile 4 (Crew) breaks it. On Boats, "Add boat" and "Export list" have tight corners, about 6 px at full size. On Crew, "Add crew member" and "Cancel" are the same height and color but have corners of about 12 px, so they look almost pill-shaped. A user who goes from Boats to Crew sees two different-looking primary buttons. That makes the product feel stitched together, and it suggests the Crew buttons might be a different kind of control when they do the same job. This is a convention: one kind of element should have one look across the set. Fix it by using one button component everywhere, with the Boats radius, since the inputs and cards elsewhere also have tight corners.

**Smaller things.**
- Tiles 1 and 2 (the Trips and Boats tables) have square outer corners. The other bordered containers have rounded corners: the stat cards on tiles 1 and 3, the Settings list on tile 5, and the Alerts list on tile 6. If tables are meant to be their own kind of element, this is fine. If not, use the same container radius everywhere.

**What's working.**
- **Same edges on every screen.** Content starts at the same left edge (about x=264) and ends at the same right edge (about x=1240). The title, subtitle and first section sit at the same heights on every screen. Moving between pages, only the content changes and nothing jumps.
- **Navigation that stays put.** The sidebar items, icons, order and active state (pale teal fill with teal bold label) are identical on all six screens, so the user always knows where they are.
- **Same headings and colors.** Every screen uses the same three-level heading scale (page title, gray subtitle, bold section heading) and the same small teal status pills, on Trips and on Boats.

Breaks: tile 4
