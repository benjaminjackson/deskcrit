**First read.** At a glance the five screens read as one product. They share the same sidebar, title-and-subtitle header, white bordered cards on a pale gray field, green accent and green status pills. The one place it stops feeling like one product is Clients (tile 3), where the content block sits a little inside the edges every other screen uses.

**Verdict.** The set mostly holds together. The one real break is tile 3: its content column is inset 8 px on both sides, so the page header and cards shift when you switch to Clients.

**Breaks**
1. **Content column edges:** tiles 1, 2, 4 and 5 keep them; tile 3 breaks them. On Overview (tile 1) at full size, the title, metric cards and table start at x = 264 and end at x = 1239. On Clients (tile 3), the title and cards start at x = 272 and end at about x = 1231, so the column is 8 px narrower on each side. On the sheet, tiles 2, 4 and 5 line up with tile 1's left and right edges. Clients is the only screen that doesn't.
   - **What the viewer experiences:** the sidebar stays still, so when you move from Overview to Clients, the big page title and the row of three metric cards jump sideways. Those cards have the same structure on both screens, which makes the shift more visible. It feels like a glitch rather than a choice, and it suggests the screen was built off the shared layout.
   - **Source:** convention. Every page in a system keeps the same margins and columns, so the content edge stays put while the content changes (Müller-Brockmann, *Grid Systems in Graphic Design*). Nothing on this screen needs a different width, so the break buys nothing.
   - **Fix:** put Clients back on the shared page container so its left edge is 264 and its right edge is 1239, like the others.

**Smaller things.** None found.

**What's working.**
- **Same sidebar on every screen.** It has the same width, item order, icons and active-state treatment (green tint plus green bold label). You always know where you are and where everything else is.
- **Same page header on every screen.** Each one uses a large bold title with a gray one-line subtitle at the same size and height. Every screen opens the same way, so you never have to work out where the page starts.
- **Same building blocks everywhere.** The white bordered card, solid-green primary button with green-outline secondary (Invoices, Reports), green status pills and section headings are styled the same wherever they appear. Each kind of element means one thing across the product.

Breaks: tile 3
