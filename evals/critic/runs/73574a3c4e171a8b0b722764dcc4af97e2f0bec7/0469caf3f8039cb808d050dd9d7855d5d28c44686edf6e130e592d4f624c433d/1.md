**First read.** All five screens read as one product. They share the same 224 px white sidebar with "Cobalt Freight" at the top, the same five nav items with the same icons, and the same pale blue highlight on the current page. On every screen the title and subtitle sit in the same spot, and content runs between the same two edges. Moving from screen to screen, only the content area changes, which is how it should be.

**Verdict.** The set holds together. At full size I found no screen that breaks the layout, the type scale, or the way elements look. The one real inconsistency is in the copy: dates are written two different ways.

**Breaks**
No break found.

**Smaller things.**
- Date format, tiles 1, 3 and 4: Shipments writes the month first ("Jun 6", "Jun 10" in the ETA column). Rates ("from 1 June") and Documents ("9 June" in the Due field) write the day first with the full month name. Someone matching an ETA on Shipments against a due date on Documents has to switch reading order. Pick one format and use it everywhere. Which one is the maker's call, based on their market (convention, Nielsen Norman Group on consistency).

**What's working.**
- **The page frame is locked down.** On every screen the sidebar is the same width, content starts at x=264 and ends at x=1240, the title sits at y≈55 and the subtitle at y≈92, and the first block starts at y≈128. Moving between pages, nothing jumps, so attention stays on what changed.
- **Each kind of element has one look.** Stat cards on Shipments and Rates use the same three-column grid, padding, number size and caption. The two tables share the same header style and row height, and the same pill badges for status. Primary and secondary buttons on Carriers and Documents are the same pair: solid blue and blue outline.
- **The type scale and colors are the same everywhere.** There are four steps on every screen: page title, section heading, body text, small label. One blue does all the work: the current nav item, buttons, badges, toggles and the truck icons. So a user learns once what blue means.

Breaks: none
