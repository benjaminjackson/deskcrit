**What changed between versions**
- **Version 1 right-aligns both description paragraphs** (seven lines, roughly x 68–588), while the "Kitchen" label, the title, the price and the button all sit on the left edge at x 68. Each line starts at a different point ("gram. Press…", "ingredient…", "between grams…"), so the reader has to find the start of every line. That slows the part of the page that explains why the scale is worth $34, and it splits the column into a left-aligned frame around a right-aligned block. This is a defect against a convention: paragraphs of several lines should be set flush left (Tschichold, *The New Typography*; Bringhurst, *The Elements of Typographic Style*, 2.1.3). Version 2 fixes it. The ragged edge moves to the right where it belongs, and the title, body, price and button now run down one clean line.
