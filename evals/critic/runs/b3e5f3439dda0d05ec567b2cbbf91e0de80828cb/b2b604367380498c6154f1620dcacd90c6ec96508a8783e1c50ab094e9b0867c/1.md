**First read.** I'm assuming this is the home page of a small local ice cream shop, meant to tell passers-by and locals what makes the shop different and when it's open. Both versions use the same layout, headline, copy, colors and hours bar. The one real difference is the paragraph text. Tile 1 sets the three paragraphs in a plain sans. Tile 2 sets them in the same brush script used for the logo and the column headings.

**Ranking**
1. Tile 1: The three paragraphs are the shop's whole pitch (the milk from one farm, the market fruit, the tub return deal), and here they read easily. The script stays on the logo and the three short headings, where it adds personality without costing anything.
2. Tile 2: The pitch is set in a script, so it reads slowly and in places is hard to make out. The script also stops marking the brand, because it now covers every element except the headline and the hours bar.

**What decides it.**
- **Paragraph face (convention: basics.md, "Paragraphs are not set in a decorative face"; Bringhurst, *The Elements of Typographic Style*, 6.2.1).**
  - **What each tile shows:** In tile 2, the paragraphs under "Our milk", "Our fruit" and "Our tubs" are four or five lines each of bold brush script at about 20 px on the full-size render. The letterforms join and slant, the x-height is small and uneven, and words like "rhubarb" and "fifty pence" take a second look. Tile 1 sets the same text in a plain upright sans.
  - **What the viewer experiences:** The viewer skims or skips the very lines that make the case for this shop over any other. That includes the one line they can act on: the fifty pence off for a returned tub. The approved fix is the direction tile 1 already takes: use a face made for reading for paragraphs, and keep script for a few words of display.
- **Typeface plan (taste, with typography.md "Typefaces in concord or in clear contrast, never in conflict" behind it).**
  - **Tile 1** has a clear three-way split: script for the brand voice, a serif for the headline, a sans for reading. Each face has one job.
  - **Tile 2** has the script fighting the serif headline for attention across the whole page. The plain sans hours bar then looks like it belongs to a different site.

Everything else matches across the two: layout, colors, headline, nav and hours bar. So this one change decides the pick.

Best: tile 1
