# Attribution

Every file in this folder was written by this project (Claude Code, for Benjamin Jackson). The ten products are invented and name no real brand. The screens are HTML pages that use no outside image, font file, or text. `build.mjs` writes each `screen-N.html`, and `render.mjs` renders each `screen-N.html` at 1280 x 800 px into `screen-N.png`. The rendering tool is the Playwright that `packs/` pins. No file here is a photograph or a screenshot of a real product.

`answers.json` names the screen that breaks the pattern in each set and the kind of break. Version 1 was run once (EV-21 run 1). Version 2 (crit-j8y.8) repairs the screens so that each set holds only its planted break; `answers.json` did not change. Version 2 is frozen after its first run.
