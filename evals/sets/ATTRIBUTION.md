# Attribution

Every file in this folder was written by this project (Claude Code, for Benjamin Jackson). The ten products are invented and name no real brand. The screens are HTML pages that use no outside image, font file, or text. `render.mjs` renders each `screen-N.html` at 1280 x 800 px into `screen-N.png`. The rendering tool is the Playwright that `packs/` pins. No file here is a photograph or a screenshot of a real product.

`answers.json` names the screen that breaks the pattern in each set and the kind of break. The sets and `answers.json` are frozen before the first live run and never changed after it (EV-21).
